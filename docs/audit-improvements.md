# Audit revision: compatibility and validation

Toolkit version **0.1.1** identifies this local revision; historical evidence pins are unchanged. This revision preserves the ten skill entrypoints and refines their decisions rather than adding a new registered parent. The motivating usage audit reported that a specimen-first rule had been read but family replication preceded comparison. The remedy makes the comparison, choice and source owner consequential; it does not claim that missing retrieval caused the behavior. The full production transcript was not inspected by this implementation session. No private art, lore, transcripts or host configuration are part of these examples.

- Director and asset-family guidance require close/play-scale comparison and a deliberate provisional choice before expansion, within existing session authorization. New shared references cover edited-source authority, explicit export, authored placement overrides, complete footprint contact including separate shelves, actionable discovery and companion knowledge/delivery. The contact guidance describes an exact geometry check and its adversarial case; no automatic checker or gameplay system is claimed.
- Blender export keeps the edited `.blend` authoritative, rejects source/output aliases and checks source bytes before/after. Mocked source preservation is tested. A real edited-object export/reimport still needs native validation.
- Candidate schema_version stays 1. New candidates add inventory_version 2, canonical relative POSIX ordering and case collision rejection. Version 1 inventories retain their original list digest; current content is compared as path/hash maps, independent of order or optional historical entry metadata. No historical records are rewritten. Every nested attachment is checked at every verdict status. New capture archives use unique IDs/paths. Listening passes now require performed, observer, route and interval facts: historical passes without them need a new actual review, not invented migration data.
- Audio defaults and direct ElevenLabs aliases remain intact; CLI adds `--provider elevenlabs|fish`. Shared claim/budget/redaction/archive utilities no longer belong to Meshy. Fish is a narrow explicit-model REST speech-to-file profile; no SFX/music/live transport is inferred. Zero budget prevents every hosted submission, even free-named models. An unknown intent with a unique recovery path precedes the POST. Received bytes remain available when validation/publication fails, with `RECEIVED_UNARCHIVED` and hash/size when metadata can be saved; disk failure may leave incomplete recovery and the initial unknown intent. Archives publish exclusively by hard link; unsupported filesystem publication retains recovery without retry. Safe request/usage metadata remains available, including ElevenLabs character-cost. See [audio recovery](../skills/studio-audio/SKILL.md).
- Imported loop endpoints use decoded duration/rate instead of compressed byte count in both the shipped example and source template. Local preparation reports endpoint fades, no crossfade and listening not_run. A loop flag does not prove an audible seam.

[Result](evidence/qoa-import.json). The custom build emitted missing-fontconfig and restricted-socket diagnostics, retained in that result. The checked import/loop assertions passed despite those unrelated diagnostics; this is not full Linux game compatibility, Godot 4.5.1 validation, target Windows validation or audible listening.

The previous [baseline validation](validation.md), tested-inputs.json and runtime-smoke.json remain historical. No new live provider, account, paid generation, desktop or source art production run was performed. Static routing/reference checks and informed review are not fresh-session behavioral validation.
