# Decoded loop units and audible seams

Measure the imported stream, not its encoded storage. In Godot `AudioStreamWAV`, `loop_begin` and `loop_end` use decoded sample frames per channel. QOA compression changes `data.size()` without changing those units. Import resampling/trimming can also change the source rate or duration. For a full imported stream use `roundi(stream.get_length() * stream.mix_rate)`; for a partial loop multiply its validated seconds by the imported mix rate. Never divide compressed byte length by PCM sample width/channels. The Python `audio.imported_loop` helper applies this contract to measured import metadata.

The original harbor template uses imported duration/rate. Run `python scripts/check_audio_import.py --godot <EXE>` to create an isolated original stereo PCM fixture, force QOA import and check actual decoded duration, storage size and loop endpoints. It uses headless Godot and isolated user/cache paths. The fixture is a representation check, not game compatibility or listening.

Endpoint fades bring each end toward silence; a true crossfade overlaps and blends tail/head and changes the effective interval. The local prepare helper implements only endpoint fades and reports `crossfade_applied: false`. Preserve original audio; record decoded and imported rates/lengths, intended interval, actual frame endpoints and treatment. Capture several complete cycles in the game and listen for clicks, dips, repetition, level and spatial context. A waveform, loop flag or player-active assertion cannot establish a seamless audible loop.

API basis: [Godot AudioStreamWAV](https://docs.godotengine.org/en/stable/classes/class_audiostreamwav.html) defines sample-based loop endpoints, mix_rate and compressed formats; [AudioStream get_length](https://docs.godotengine.org/en/stable/classes/class_audiostream.html#class-audiostream-method-get-length) returns seconds. The actual fixture check is scoped to the engine recorded in its evidence, not every documented engine version.
